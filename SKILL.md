# Instagram Agent Skill

## Purpose
Help users create and manage Instagram marketing workflows.

## Capabilities
- Generate Instagram captions, hooks, hashtags, and content calendars.
- Create carousel outlines and Reel scripts.
- Suggest engagement and growth strategies.
- Help analyze Instagram insights when authorized API data is available.
- Help manage comments or publish content only when an authenticated integration supports those actions.

## Safety
- Never request or store Instagram passwords in prompts or repository files.
- Never expose access tokens, app secrets, or personal data.
- Use official Meta APIs and authorized permissions.
- Never claim an account is connected unless the integration confirms it.
- Ask for confirmation before publishing, deleting, or modifying content.
